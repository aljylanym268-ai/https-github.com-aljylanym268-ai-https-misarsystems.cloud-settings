إنشاء Storage Buckets

هذا الملف يقوم بإنشاء جميع حاويات التخزين (Buckets) المطلوبة لتطبيق Misar Systems في Supabase.
مطلوب: استخدام Service Role Key (وليس Anon Key) لإنشاء buckets.

الطريقة الموصى بها: استخدام SQL Editor

  1. اذهب إلى Supabase SQL Editor
  2. انسخ محتوى ملف create-buckets.sql (بجانب هذا الملف)
  3. الصقه في الـ SQL Editor واضغط Run
  4. عد إلى هنا واضغط التحقق من الـ Buckets
product-images
صور المنتجات - عام
⏳
review-media
صور وفيديوهات التقييمات - عام
⏳
user-images
الصور الشخصية للمستخدمين - عام
⏳
banner-images
صور الإعلانات - عام
⏳
property-images
صور العقارات - عام
⏳
ملاحظة: بعد إنشاء الـ buckets، ارجع للصفحة الرئيسية واضغط F5 (تحديث).
إذا استمرت المشكلة، تأكد من أنك تستخدم Service Role Key (وليس Anon Key).
يمكنك الحصول على Service Role Key من: Supabase Dashboard → Settings → API → service_role key.
